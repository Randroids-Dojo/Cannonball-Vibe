# Revision20 original cabin construction

The original eight back bolsters use sixteen-point elliptical rings and eight
cross sections, with rounded ends and the existing18-degree front/9-degree rear
seat rake. Their original lowest point is retained. Their complete section
table is locked in specification.json; native trials save1504LOD0 triangles.

The two previous closed cup pads become real32-sided molded inserts with40mm
minimum receiving radius,60mm depth,3mm bottom and1.5mm walls. Two actual console
pockets provide nominal1.2mm wall/bottom clearance. Only the finite annular
flange seats against the unchanged evaluated console top. Local native proof
checks the entire pocket domain and rejects both an uncut console and a200um
downward insert displacement. This change costs592LOD0 triangles.

Charcoal thread uses linear RGB0.040/0.045/0.050 and roughness0.78. Existing
physical seam routes, materials count and original provenance remain intact.
The actual matched Blender close-ups support these changes; they do not grant
human visual approval or prove the final runtime presentation.

Before delivery, check the complete new source, all moving clearances, every
LOD, byte-identical exports and clean runtime import. Extend the independent
static certificate with the actual finite cup seats and malformed-placement
controls. No allowance for arbitrary cup/console intersection is authorized.
Engineering dimensions, hardpoints, physics, input policy and budgets stay
unchanged. Rear wheel-tub trim and fascia remain outside this lock.
